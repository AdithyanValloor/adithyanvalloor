## 🧑‍💻 About Me

I'm a **backend-focused full stack developer** who enjoys going beyond simply making applications work.

I like understanding **what happens underneath the code** — from JavaScript's execution model and Node.js internals to databases, networking, containers, reverse proxies, distributed communication, CI/CD, and production systems.

🚀 I build real-world applications with **TypeScript + Node.js**

🏗️ I design modular and distributed backend architectures

🐳 I containerize and deploy applications using **Docker**

🔄 I build **CI/CD pipelines** with GitHub Actions

🌐 I work with **Nginx, HTTPS, domains, Linux and cloud infrastructure**

📊 I'm currently diving deeper into **observability, logging and production reliability**

🧠 I enjoy learning through **building, breaking, debugging and rebuilding**
